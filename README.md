# Automatic_Mouse

یک برنامه کاربردی برای آموزش دادن به موس و ذخیره کردن رفتار موس برای کارهایی که مرتبا انجام میدهید 
و نیاز به تحلیل ندارد.
درواقع این برنامه میتواند حرکات موس را که قبلا شما آنها را انجام داده اید ذخیره کند و آنها راتقلید کند .
شما میتوانید برای کار های مختلف موس را برنامه ریزی کنید و در زمان نیاز از از آن استفاده نمایید .
امیدوارم از آن لذت ببرید.

An application to train the mouse and save mouse behavior for tasks that you do regularly and do not need analysis.

In fact, this program can save the mouse movements that you have previously performed and imitate them.

You can program the mouse for different tasks and use it when needed.

I hope you enjoy it.
