# Automatic_Mouse

یک برنامه کاربردی برای آموزش دادن به موس و ذخیره کردن رفتار موس برای کارهایی که مرتبا انجام میدهید و نیاز به تحلیل ندارد.

درواقع این برنامه میتواند حرکات موس را که قبلا شما آنها را انجام داده اید ذخیره کند و آنها راتقلید کند .

شما میتوانید برای کار های مختلف موس را برنامه ریزی کنید و در واقع نیاز از آن استفاده نمایید .

امیدوارم از آن لذت ببرید.
